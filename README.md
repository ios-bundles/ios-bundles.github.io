# Пакеты сотовой связи Apple

Интерактивная таблица для подбора пакетов оператора (carrier bundles) из прошивки iOS по требованиям: VoLTE, VoWiFi, EVS, 5G, MMS, FaceTime и т. д. Каждое требование можно выключить, сделать желательным или обязательным. Страница пересчитывает таблицу сразу, а настройки посетителя хранятся в его браузере.

Вверху — переключатели языка (русский по умолчанию, английский) и темы (светлая по умолчанию, тёмная); выбор тоже запоминается в браузере.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | страница целиком (стили и скрипт внутри, без сборки) |
| `data.json` | данные пакетов, извлечённые из IPSW |
| `defaults.json` | требования по умолчанию — **правьте здесь** |
| `tools/build_data.py` | пересборка `data.json` из распакованных пакетов |

## Публикация на GitHub Pages

1. Положите содержимое этой папки в репозиторий (в корень или в `docs/`).
2. Settings → Pages → Deploy from a branch → выберите ветку и папку.
3. Откройте `https://<user>.github.io/<repo>/`.

Локально страницу нужно открывать через веб-сервер (браузер не даёт загружать `data.json` с `file://`):

```bash
python3 -m http.server 8000
```

## Умолчания требований (`defaults.json`)

```json
"imsProto": { "mode": "req", "params": { "set": ["v46", "unset"] } }
```

- `mode`: `off` — выключено, `pref` — желательно, `req` — обязательно.
- `params` — параметры требования (у тех, где они есть).
- `table.maxRed` — сколько невыполненных обязательных допускает фильтр при открытии (`0`, `1`, `2` или `99` = все); `table.showOffColumns` — показывать столбцы выключенных требований.

Проще всего: настройте требования на странице и нажмите «Скопировать настройки» — в буфер попадёт готовый `defaults.json`. После изменения файла у посетителей сохранённые настройки сбрасываются к новым умолчаниям.

| id | Требование | params |
|---|---|---|
| `apnEdit` | APN интернета можно редактировать | — |

| `inetProto` | протокол APN интернета | `set`: из `v46`, `v4`, `v6`, `unset` |
| `mms` | настройки MMS | `v`: `empty` / `filled` |
| `mmsEdit` | APN MMS можно редактировать | — |
| `ims` | IMS (VoLTE) поддерживается | — |
| `evs` | кодек EVS | — |
| `volteDef` | VoLTE включён по умолчанию | — |
| `volteKey` | переключатель VoLTE в настройках (ключ ShowVolteSwitch) | — |
| `xcap` | доп. услуги через XCAP | — |
| `vvm` | нет визуальной голосовой почты | — |
| `vmpilot` | нет чужого номера голосовой почты | — |
| `epdg` | ePDG не зашит на чужого оператора | — |

## Обновление данных

Распакуйте из IPSW пакеты операторов (`System/Library/Carrier Bundles/iPhone/*.bundle`, включая `Default.bundle`) и выполните:

```bash
python3 tools/build_data.py <папка_с_пакетами> 27.0 24A437 iPhone18,3 "iPhone 17" V53_V54_V57 > data.json
```

Скрипт читает plist напрямую и собирает настройки как iOS: `overrides_<плата>.plist` (для iPhone 17 — `V53_V54_V57`) глубоко сливается поверх `carrier.plist`; отсутствующие ключи берутся из `Default.bundle`, а затем из значений по умолчанию CommCenter (`CODE_DEFAULTS` в скрипте).

Все выводы — по содержимому пакетов, не проверка на устройстве.
